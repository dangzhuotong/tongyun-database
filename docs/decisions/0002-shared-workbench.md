# 0002 · 人与 AI 共用的可追溯数据库工作台

状态：首个 SQLite 纵向切片已实施；生产及桌面适配待实现。日期：2026-10-16。

用户明确要求 UI、参考 Dev/Git/API 与 Navicat、打通 AI 交互、每步可追溯、更新必须带回滚 SQL、百万级数据默认 1000 行。因此将原纯数据库模板仓扩展为工作台；旧 README 的“本轮只建文档”已被本次实现请求替代。

选择共享安全核心 + 本机 HTTP + UI/CLI 双入口，先用 Node 内置 SQLite 和零第三方依赖完成真实执行闭环。ORM 不参与安全决策；Drizzle/D1 仍是候选而非已实现栈。

对比：先做桌面壳会延迟验证执行/回滚语义；只做 skill/文档无法让用户审查操作。先完成本机 Web 纵向切片，保留未来 Tauri / 驱动 / MCP 适配边界。

回滚不能仅反转 SQL 文本：需真实前后快照、整行冲突检查和结果验证。含触发器、外键或复杂结构时首版拒绝写入。执行与审计同库事务保证本地一致性，代价是不能直接接生产，后续需解决独立审计的可靠投递与授权。

查询在隔离进程中执行，使用只读连接和授权器；表浏览以主键游标分页，拒绝无整数主键的自动分页。结果限制同时覆盖行数和字节，UI 使用虚拟滚动。性能证据范围见 testing，不承诺任意 SQL 或远程数据库性能。
