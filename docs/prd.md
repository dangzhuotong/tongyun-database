# PRD：橦云数据库

## 产品目标

让人和外部 AI Agent 共用同一个数据库操作工作台。AI 操作可观察、可追溯；变更必须具备可执行的回滚材料。用户可从界面审查、执行、接管与恢复。

## 首版需求

| ID | 场景与规则 | 可观察结果 |
| --- | --- | --- |
| R-01 | 本地工作台展示连接、表树、SQL 编辑器、结果和结构 | 启动可浏览合成 SQLite 数据，明暗主题可切换 |
| R-02 | 人与 Agent 共用 API、计划及事件 | Agent 创建的计划按相同 task 在 UI 出现 |
| R-03 | 每次能力发现、结构读取、查询、计划读取、预览、确认、取消、执行、回滚留记录 | 可查看 actor、task、环境、操作编号、时间、结果及失败码；SQL 在私有查询表可查 |
| R-04 | UPDATE 先读取真实单行，生成配套 SQL / 参数及指纹 | 预览后业务数据不变，审查能看到前后值及回滚材料 |
| R-05 | 执行须提交匹配指纹，核对结构、旧值和行数 | 未确认 / 旧值变化 / 结构变化均失败；SQLite 成功写入和审计同事务，远程遵循 R-15 |
| R-06 | 回滚需再次确认并核对整行新值 | 恢复原字段含 NULL；后续被别人修改则拒绝；重复请求不重复写入 |
| R-07 | SQL 查询只读、最多 1000 行 / 2 MiB / 2 秒 | 越界结果截断；超时终止独立进程；数据表浏览走整数主键游标 |
| R-08 | 大结果集界面虚拟滚动，不自动全表计数 | 1000 行数据只渲染可视行与缓冲；百万行基准记录实际数据规模及执行计划 |
| R-09 | 本地调用有来源检查和令牌验证 | 外部 Origin / 非预期 Host / 缺令牌被拒绝，令牌不出现在日志 |

## 当前范围与后续

当前包含 SQLite、MySQL 和 Redis 7+ 面板。SQL 变更只支持单行 UPDATE；Redis 支持受控单 Key 编辑、TTL 与删除恢复。外部 Agent 可接入，不内置模型。actor/task 为标签而非真实身份，digest 是防止确认错计划的绑定信息，不是权限凭证。

后续：连接编辑/移除、PostgreSQL、身份与授权范围；INSERT / DELETE 的可靠补偿；批量与迁移恢复；MCP；桌面安装包。每种后端独立验证事务、锁、类型和回滚语义，不能宣称 SQLite 结果可直接推广到生产。

## 多引擎需求

| ID | 规则 | 验收 |
| --- | --- | --- |
| R-10 | 添加 MySQL/Redis 连接，密码加密保存且不返回，默认只读 | 可保存/测试/选择连接；生产写入配置拒绝 |
| R-11 | MySQL 基础表/按需结构/受限 SELECT/主键分页 | 精确显示 BIGINT/DECIMAL；查询不能写入、跨库或调用任意函数；最多 1000 行 |
| R-12 | MySQL 单行 UPDATE 真实预览与整行并发检查 | 预览不落库，指纹错误/数据变化拒绝，回滚恢复旧值；不能判定安全的表拒绝 |
| R-13 | Redis SCAN 和五种常见类型编辑 | 无 KEYS；不丢弃超过页大小的游标批次；编辑均有原 DUMP 恢复快照 |
| R-14 | Redis 保留原 TTL，检查新值与绝对过期时间后回滚 | 删除可恢复；外部写入拒绝覆盖；原到期时间已过则拒绝复活 |
| R-15 | 远程执行意图先落盘，未知结果不可重复执行 | 故障注入后 unknown，第二次调用不重复远程写入 |
| R-16 | 同连接下的人与 Agent 共用计划、审计和私有请求参数 | Header 选择连接；计划跨连接/任务拒绝；UI 可查看原始操作参数 |
